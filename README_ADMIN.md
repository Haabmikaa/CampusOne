# CampusOne: Administrator Dashboard Guide

Welcome to the **CampusOne Admin Panel**. This web-based dashboard is the central control center for managing the entire campus ecosystem.

## 🌐 Dashboard Flow

### 1. Admin Login
Secure access to the management tools.

![Admin Login](screenshots/admin/login.png)
*   **Authentication**: Multi-factor authentication support for high-level campus admins.

### 2. User & Department Management
Manage the campus population and organizational structure.

![User Management](screenshots/admin/users.png)
*   **Students/Staff**: View, edit, or disable user accounts.
*   **Departments**: Create and manage academic or administrative departments.
*   **Staff Catalogs**: Create specialized categories (e.g., "Maintenance", "Security") for easier task assignment.

### 3. Schedule Orchestration
The primary tool for managing academic time.

![Schedules](screenshots/admin/schedules.png)
*   **Class Schedules**: Create recurring weekly timetables for different sections and groups.
*   **Exam Schedules**: Publish official exam periods with venue assignments.
*   **Real-time Updates**: Changes are instantly pushed to all student devices.

### 4. Complaint & Service Resolution
Monitor and resolve campus-wide issues.

![Complaints Management](screenshots/admin/complaints.png)
*   **Incident Queue**: View all incoming complaints from students and staff.
*   **Smart Assignment**: Assign complaints to specific staff members based on their catalog (e.g., plumbing issues to Maintenance).
*   **Resolution Tracking**: Monitor the time-to-resolve and quality of service.

### 5. Broadcasts & Emergency Alerts
Communicate with the entire campus or specific groups.

![Broadcasts](screenshots/admin/broadcasts.png)
*   **Global News**: Send news that appears on everyone's home screen.
*   **Push Notifications**: Send instant alerts for emergencies or critical updates.

### 6. Assignment Configuration
Setup the academic structure for student registration.

![Assignment Setup](screenshots/admin/assignments.png)
*   **Sections & Groups**: Configure how many sections and groups exist for each cohort (e.g., standardizing to 6 Sections and 6 Groups).

### 7. Campus Events & Tasks
Manage non-academic campus activities.

![Events](screenshots/admin/events.png)
*   **Event Calendar**: Schedule seminars, workshops, and student festivals.
*   **Task Lists**: Manage internal admin tasks and project milestones.

### 8. System Support & Settings
Configure the underlying app parameters.

![Settings](screenshots/admin/settings.png)
*   **Global Config**: Manage app themes, feature flags, and API integrations.
*   **Admin Support**: Contact technical support or view system logs.
